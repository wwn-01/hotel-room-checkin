## 报价模式选择

选用：**一次性实施费 + 年度服务费 + 超量单价条款**（课件推荐组合模式）。

理由：人力与数据属于一次性交付，对应实施费；模型、云资源与运维属于持续支出，对应年服务费；用量波动由年包干 1.6 亿 Token/年与超量单价承接，风险不由我方毛利吞下。

## 咬合校验

- 人力：练2 合计 23 人天 × 1,960 元 = 45,080 元；对外单价 2,450 元/人天。
- 模型：练3 基准档月 17.45 元 × 12 = 209.40 元 = 报价单模型费。
- 算力：练4 推荐云端 API，云资源 7,200 元/年；临界月 Token 9.72 亿，当前 0.12 亿在 API 侧。
- ROI：练5 一次性投入 88,391.01 元 = 本表首年合计；回本 25.97 个月。
