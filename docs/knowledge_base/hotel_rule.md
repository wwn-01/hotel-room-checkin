# hotel_rule.md｜山海旅居 房态协同知识库
## 业务核心规则
1. **房态判定**
   - ✅【清扫完成 + 质检通过】→ 房间标记为可入住
   - ✅ 如果仅清扫完成、质检未通过：不可直接入住
   - ✅ 如果房间维修中：锁定，禁止分配给客人
2. **角色清单**
   - 前台：查询房态、发起工单、接待客人
   - 客房调度：安排清扫任务
   - 质检：查房，提交质检结果
   - 管理员：全部权限、查看审计日志
3. **智能体约束**
   - 智能体只生成建议、工单、提醒；不能直接开锁、不能强制核验客人
   - 异常（冲突、维修、核查失败）必须转人工处理
4. **数据记录要求**
   - 所有状态变更、操作记录存入审计日志
5. **演示模式说明**
   - MVP 使用模拟数据演示；可不依赖大模型密钥

## 业务流程
客人准备入住 → 查询房间 → 判断房态；不合格生成质检 / 复查工单；全部通过才允许办理入住。
