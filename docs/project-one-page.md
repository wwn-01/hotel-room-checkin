# 项目一页纸｜山海旅居
| 要填的五项 | 山海旅居（填写内容） | 为什么先定它 |
| ---- | ---- | ---- |
| 客户是谁 | 短途出游旅客、民宿房东，课程项目小组牵头 | 决定报价模式与产品面向对象 |
| 多少人用 | 100 名注册旅客 + 5 名入驻房东 + 1 名平台管理员 | 决定并发与服务口径 |
| 每天多少量 | 月均约 30 笔预订订单，日均几十次房源浏览查询 | Token 与算力测算的起点 |
| 数据在哪 | 用户、房源、订单存后端数据库；房源图片放在云对象存储 | 决定数据与对接工作量 |
| 能不能上云 | 可部署上云，调用云端服务 | 一票否决项：决定 API 还是私有化 |
